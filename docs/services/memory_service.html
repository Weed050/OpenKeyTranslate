services.memory_service

Correction Memory Service

Implements the project's core engineering-thesis contribution: a lightweight, local retrieval mechanism over the user's confirmed translations - a per-project translation memory (TM), used for adaptive MT by in-context learning (Moslem 2024, "Language Modelling Approaches to Adaptive Machine Translation", ch. 4: fuzzy matches from a TM injected into the prompt as source -> target pairs).

Each time a bubble is about to be translated, its English source text is embedded and compared (cosine similarity) against every TM entry stored for the same project. Close-enough matches are injected into the LLM prompt as EN -> PL example pairs (see translation_service.py / providers/prompts.py), pushing the model toward phrasing the user has already approved for similar text.

Two kinds of entries (Correction.kind): - "corrected": the user changed the AI proposal - the strongest signal. The rejected AI version is kept (ai_translation) and shown to the model as "rejected", so it also learns what NOT to write. - "approved": the user explicitly approved the AI proposal unchanged ("Approve to memory" button, only with memory_store_approved on - off by default). A plain TM entry: it keeps character voice / recurring lines consistent and makes the memory fire far more often. Corrected entries win ties at retrieval.

Design notes: - Embeddings are computed locally (sentence-transformers), matching the project's privacy-first / local-processing design pillar. - Matching is deliberately scoped per-project: reusing a phrase's translation across unrelated manga titles risks bleeding one series' voice into another. - At the data scale of a thesis project (hundreds to a few thousand entries), a brute-force cosine scan over embeddings loaded into memory is simpler to reason about and fast enough - no vector DB needed. - Source text is normalized before embedding / exact matching (utils/ocr_textfix: "SQUAD- RON" -> "SQUADRON"), so entries saved before the OCR cleanup existed still match cleaned text. Entries embedded from un-normalized text can be refreshed with reembed_project() (POST /corrections/reembed/{project}). - Two retrieval lanes, chosen by the length of the text being translated (see is_short_phrase): * Longer text -> "fuzzy" lane: up to top_k entries that clear BOTH the cosine threshold and a lexical gate (content-word overlap, memory_lexical_min) - unless the cosine alone is very high (memory_strong_similarity). all-MiniLM-L6-v2 scores "same topic, different line" around 0.7; such matches are noise as examples (Moslem 2024: low-similarity fuzzy matches add little). * Short text (<= MEMORY_SHORT_PHRASE_MAX_WORDS words: interjections, sound effects) -> "exact" lane: EXACT match on normalized text. Short entries are never embedding-searched, and short text is never embedding-matched against long entries either.

 73def _get_embedder():
 74    """
 75    Lazily initialize and return a singleton SentenceTransformer instance.
 76
 77    Deferred import/instantiation keeps startup fast for code paths that
 78    never touch the memory system, and mirrors the singleton pattern already
 79    used for the translation client in translation_service.py.
 80    """
 81    global _embedder
 82    if _embedder is None:
 83        with _embedder_lock:                 # a request arriving mid warm-up waits for it instead of loading a 2nd copy
 84            if _embedder is None:
 85                import time
 86                started = time.monotonic()
 87                EMBEDDER_STATE.update(state="loading", error=None)
 88                try:
 89                    from sentence_transformers import SentenceTransformer
 90                    _embedder = SentenceTransformer(MEMORY_EMBEDDING_MODEL)
 91                except Exception as e:
 92                    EMBEDDER_STATE.update(state="error", error=f"{type(e).__name__}: {e}")
 93                    raise
 94                EMBEDDER_STATE.update(state="ready", seconds=round(time.monotonic() - started, 1))
 95    return _embedder

 98def warm_up_embedder_async() -> threading.Thread:
 99    """
100    Load the embedding model in a background thread (called from main.py's lifespan). The app starts serving at once;
101    the ~5-30 s model load (torch import + huggingface cache check) no longer delays startup, and users who open
102    the app only to browse pages never pay for it. If a translation or a correction-save needs the model before
103    the thread is done, it simply waits on the same lock. A failed load is recorded in EMBEDDER_STATE (health banner).
104    """
105    def _run():
106        try:
107            _get_embedder()
108            print(f"[MEMORY] embedder ready in {EMBEDDER_STATE['seconds']}s (background warm-up).")
109        except Exception as e:
110            print(f"[MEMORY] WARNING embedder failed to load: {type(e).__name__}: {e}")
111    t = threading.Thread(target=_run, name="embedder-warmup", daemon=True)
112    t.start()
113    return t

121@lru_cache(maxsize=8192)
122def memory_text(text: str) -> str:
123    """
124    The form of a source line used for embedding and exact matching: OCR artefacts fixed ("SQUAD- RON" ->
125    "SQUADRON", LNIT -> UNIT) and whitespace collapsed. Never stored - the Correction keeps what the user saw.
126    """
127    text = " ".join((text or "").split())
128    if not text:
129        return ""
130    try:
131        from utils.ocr_textfix import fix_ocr_text
132        return fix_ocr_text(text)
133    except Exception:
134        return text   # wordfreq missing / unexpected input: matching on the raw text is still fine

137def embed_text(text: str) -> np.ndarray:
138    """Compute a single L2-normalized embedding vector for a piece of (already normalized) text."""
139    vector = _get_embedder().encode(text, normalize_embeddings=True)
140    return np.asarray(vector, dtype=np.float32)

156def normalize_phrase(text: str) -> str:
157    """
158    Case-, punctuation- and whitespace-insensitive key for exact matching:
159    "WAIT!", "Wait..." and "  wait " all become "wait". Returns "" for
160    punctuation-only text ("?!", "...") - callers must treat that as
161    "nothing to match on".
162    """
163    stripped = _PUNCT_RE.sub("", (text or "").lower())
164    return " ".join(stripped.split())

167def is_short_phrase(text: str) -> bool:
168    """
169    True when `text` belongs to the exact-match lane: at most
170    MEMORY_SHORT_PHRASE_MAX_WORDS whitespace-separated words. Setting that
171    to 0 turns the lane off (only empty text counts as "short" then, and
172    empty text is never translated or stored).
173    """
174    return len((text or "").split()) <= get_setting("memory_short_phrase_max_words", 2)

182def _latest_per_source(corrections: list[Correction]) -> list[Correction]:
183    """
184    One entry per normalized source line: the most recent one (the user's latest decision). Keeps a stale
185    first translation of a line from competing with the newer one as a second "example" of the same sentence.
186    """
187    latest: dict[str, Correction] = {}
188    for c in corrections:
189        key = normalize_phrase(memory_text(c.source_text)) or c.source_text
190        if key not in latest or c.id > latest[key].id:
191            latest[key] = c
192    return list(latest.values())

195def _find_exact_phrase_match(source_text: str, corrections: list[Correction]) -> list[tuple[Correction, float]]:
196    """
197    Exact-match lane: the user's most recent translation of this exact line
198    (compared via normalize_phrase). Returns at most one (Correction, 1.0) -
199    if the user changed their mind over time, the latest decision wins.
200    """
201    key = normalize_phrase(memory_text(source_text))
202    if not key:
203        return []
204    candidates = [c for c in corrections if normalize_phrase(memory_text(c.source_text)) == key]
205    if not candidates:
206        return []
207    latest = max(candidates, key=lambda c: c.id)
208    return [(latest, 1.0)]

217def _content_words(text: str) -> set[str]:
218    return {w for w in normalize_phrase(text).split() if w not in _STOPWORDS and len(w) > 1}

221def lexical_overlap(a: str, b: str) -> float:
222    """
223    0-100: Jaccard overlap of CONTENT words (stopwords dropped). Measured on the project's own logs it separates
224    useful fuzzy matches ("FLAG OF QUA-TOYNE PRINCIPALITY" ~ "QUA-TOYNE PRINCIPALITY": 67) from same-topic noise
225    ("PLEASE USE THE WYVERNS WE PROVIDED..." ~ "ONLY WYVERNS CAN TAKE DOWN WYVERNS...": 8) far better than
226    rapidfuzz's token_set_ratio, which scored both around 45-100.
227    """
228    wa, wb = _content_words(a), _content_words(b)
229    if not wa or not wb:
230        return 0.0
231    return 100.0 * len(wa & wb) / len(wa | wb)

234def find_top_matches(
235        source_text: str,
236        project_id: int,
237        db: Session,
238        threshold: float | None = None,
239        top_k: int | None = None,
240        corrections: list[Correction] | None = None,
241) -> list[tuple[Correction, float]]:
242    """
243    Find this project's TM entries relevant to `source_text`.
244
245    Short text (see is_short_phrase) -> exact-match lane: at most one entry,
246    score 1.0. Longer text -> fuzzy lane: up to `top_k` entries whose cosine
247    similarity clears `threshold` AND whose word overlap clears memory_lexical_min (or whose cosine alone clears
248    memory_strong_similarity), best first; corrected entries win near-ties; one entry per source line and no two
249    examples with the same final translation.
250
251    :param source_text: The English OCR text about to be translated.
252    :param project_id: Restricts the search to entries from the same project.
253    :param db: Active SQLAlchemy session.
254    :param threshold: Minimum cosine similarity (fuzzy lane only).
255    :param top_k: Maximum number of matches (fuzzy lane only).
256    :param corrections: Pre-loaded entries of this project (translate_bubbles loads them once per page).
257    :return: List of (Correction, cosine score), best first. Empty if nothing matches.
258    """
259    if threshold is None:
260        threshold = get_setting("memory_similarity_threshold", 0.67)
261    if top_k is None:
262        top_k = get_setting("memory_top_k", 3)
263    lexical_min = get_setting("memory_lexical_min", 25) or 0
264    strong = get_setting("memory_strong_similarity", 0.90)
265
266    if corrections is None:
267        corrections = db.query(Correction).filter(Correction.project_id == project_id).all()
268    if not corrections:
269        return []
270
271    if is_short_phrase(source_text):
272        return _find_exact_phrase_match(source_text, corrections)
273
274    candidates = [c for c in _latest_per_source(corrections) if not is_short_phrase(c.source_text)]
275    if not candidates:
276        return []
277
278    query = memory_text(source_text)
279    query_vector = embed_text(query)
280    stored_vectors = np.stack([decode_embedding(c.embedding) for c in candidates])
281
282    # Vectors are pre-normalized at encode time, so the dot product IS the cosine similarity.
283    similarities = stored_vectors @ query_vector
284
285    scored = []
286    for idx, sim in enumerate(similarities):
287        sim = float(sim)
288        if sim < threshold:
289            continue
290        c = candidates[idx]
291        if sim < strong and lexical_min and lexical_overlap(query, memory_text(c.source_text)) < lexical_min:
292            continue
293        rank = sim + (_CORRECTED_BONUS if entry_kind(c) == "corrected" else 0.0)
294        scored.append((rank, sim, c))
295    scored.sort(key=lambda t: t[0], reverse=True)
296
297    results: list[tuple[Correction, float]] = []
298    seen_finals: set[str] = set()
299    for _, sim, correction in scored:
300        if len(results) >= top_k:
301            break
302        final_key = correction.final_translation.strip().lower()
303        if final_key in seen_finals:
304            continue
305        seen_finals.add(final_key)
306        results.append((correction, sim))
307    return results

321def save_correction(
322        db: Session,
323        project_id: int,
324        source_text: str,
325        ai_translation: str | None,
326        final_translation: str,
327        approve: bool = False,
328) -> Correction | None:
329    """
330    Persist a confirmed translation and its embedding as a TM entry - subject to a few
331    quality gates, so the memory only grows from signal, not noise:
332
333    - Kind: final != AI proposal -> "corrected". final == AI proposal (the user accepted it unchanged) ->
334      "approved" only for an explicit approval (approve=True) with memory_store_approved on, otherwise nothing.
335      Off by default: approved entries are the model's own text fed back to it as examples, and moving on from a
336      bubble used to approve it silently (an accidental "WIWERN" became memory that way).
337    - Junk gate (longer sources only): skip fragments whose final translation
338      is shorter than MEMORY_MIN_WORDS.
339    - Short-phrase lane: sources of <= MEMORY_SHORT_PHRASE_MAX_WORDS words
340      (interjections, sound effects) are exempt from the junk gate, because
341      they are retrieved by EXACT match (see find_top_matches), not by
342      embeddings. Punctuation-only sources ("?!", "...") have nothing to match on and are skipped.
343    - Duplicate gate: skip re-saving what the latest stored entry for the same source already says
344      (an approval of a line that already has that translation adds nothing).
345
346    Every bubble is still stored as a new row when it passes (entries are never overwritten in place); retrieval
347    uses the latest entry per source line.
348
349    :return: The created Correction, or None if a gate skipped the save.
350        Callers should treat None as "acknowledged, not stored" - not an error.
351    """
352    final_clean = final_translation.strip()
353    ai_clean = (ai_translation or "").strip()
354
355    kind = "corrected"
356    if final_clean.lower() == ai_clean.lower():
357        if not (approve and get_setting("memory_store_approved", False)):
358            return None
359        kind = "approved"
360
361    short_lane = is_short_phrase(source_text)
362    phrase_key = normalize_phrase(memory_text(source_text))
363
364    if not final_clean:
365        return None   # a cleared textbox must never become a stored (empty) hint
366    if short_lane:
367        if not phrase_key:
368            return None
369    elif len(final_clean.split()) < get_setting("memory_min_words", 3):
370        return None
371
372    # Duplicate gate: the most recent stored entry for this source (normalized - "WAIT!" == "WAIT...",
373    # "SQUAD- RON" == "SQUADRON") already has this exact final_translation (case-insensitive - the provider
374    # sometimes returns lowercase, sometimes UPPERCASE). Repeated "Next" clicks / double-submits don't clone rows.
375    history = (
376        db.query(Correction)
377        .filter(Correction.project_id == project_id)
378        .order_by(Correction.id.desc())
379        .all()
380    )
381    last = next((c for c in history if normalize_phrase(memory_text(c.source_text)) == phrase_key), None)
382    if last is not None and last.final_translation.strip().lower() == final_clean.lower():
383        return None
384
385    correction = Correction(
386        project_id=project_id,
387        source_text=source_text,
388        ai_translation=ai_translation,
389        final_translation=final_clean,
390        kind=kind,
391        embedding=encode_embedding(embed_text(memory_text(source_text))),
392    )
393    db.add(correction)
394    db.commit()
395    db.refresh(correction)
396    return correction

399def reembed_project(db: Session, project_id: int) -> int:
400    """
401    Recompute every entry's embedding from the normalized source (memory_text). Needed once for entries saved
402    before the OCR cleanup / normalization existed, or after changing memory_embedding_model. Returns the count.
403    """
404    rows = db.query(Correction).filter(Correction.project_id == project_id).all()
405    for c in rows:
406        c.embedding = encode_embedding(embed_text(memory_text(c.source_text)))
407    db.commit()
408    return len(rows)

411def _set_final(correction: Correction, new_final: str) -> None:
412    """Change a stored entry's final text, keeping the first-saved version (final_before_edit) for the evaluation."""
413    if correction.final_before_edit is None:
414        correction.final_before_edit = correction.final_translation
415    correction.final_translation = new_final
416    correction.edited_at = datetime.now(timezone.utc)
417    if (correction.ai_translation or "").strip().lower() != new_final.strip().lower():
418        correction.kind = "corrected"     # an edited approval is the user's own wording now

421def edit_correction(db: Session, correction_id: int, new_final: str) -> Correction | None:
422    """
423    Inline edit from the Memory page. The embedding is NOT recomputed - it is built from the English source, which
424    does not change. None when there is no such entry.
425    """
426    correction = db.query(Correction).filter(Correction.id == correction_id).first()
427    if correction is None:
428        return None
429    new_final = new_final.strip()
430    if new_final and new_final != correction.final_translation:
431        _set_final(correction, new_final)
432        db.commit()
433        db.refresh(correction)
434    return correction

437def _same_case(original: str, replacement: str) -> str:
438    """Give the replacement the letter case of the text it replaces (memory is mostly ALL CAPS)."""
439    if original.isupper():
440        return replacement.upper()
441    if original.islower():
442        return replacement.lower()
443    if original[:1].isupper() and original[1:].islower():
444        return replacement[:1].upper() + replacement[1:].lower()
445    return replacement

448def replace_in_memory(db: Session, project_id: int, find: str, replace: str, mode: str = "word",
449                      ids: list[int] | None = None, apply: bool = False) -> list[dict]:
450    """
451    Find & replace in the stored final translations of one project (the Memory page; also offered after a glossary
452    term is accepted, so old entries stop contradicting it).
453
454    mode "word":   whole words only, case-insensitive (WIWERN, not WIWERNY).
455    mode "prefix": words STARTING with `find` - the term and its Polish inflected forms: find "WIWERN" ->
456                   WIWERN, WIWERNY, WIWERNAMI, each keeping its own ending (WYWERN, WYWERNY, WYWERNAMI).
457    The replacement takes the letter case of what it replaces. Only `ids` are changed when given (the user unticked
458    the rest of the preview). apply=False is a dry run.
459
460    :return: [{"id", "source_text", "before", "after"}] for every entry that changes.
461    """
462    find = (find or "").strip()
463    if len(find) < 2:
464        return []
465    word = re.escape(find)
466    if mode == "prefix":
467        pattern = re.compile(rf"(?<!\w){word}(\w*)", re.IGNORECASE)
468
469        def substitute(m):
470            rest = m.group(1)
471            return _same_case(m.group(0)[:len(m.group(0)) - len(rest)], replace) + rest
472    else:
473        pattern = re.compile(rf"(?<!\w){word}(?!\w)", re.IGNORECASE)
474
475        def substitute(m):
476            return _same_case(m.group(0), replace)
477
478    wanted = set(ids) if ids is not None else None
479    changes = []
480    rows = db.query(Correction).filter(Correction.project_id == project_id).order_by(Correction.id.desc()).all()
481    for c in rows:
482        if wanted is not None and c.id not in wanted:
483            continue
484        after = pattern.sub(substitute, c.final_translation)
485        if after == c.final_translation:
486            continue
487        changes.append({"id": c.id, "source_text": c.source_text, "before": c.final_translation, "after": after})
488        if apply:
489            _set_final(c, after)
490    if apply and changes:
491        db.commit()
492    return changes

495def delete_correction(db: Session, correction_id: int) -> bool:
496    """
497    Permanently remove a correction from memory (the "trash" action in the
498    TM analytics panel, for a hint that's gone stale or was a mistake).
499
500    :return: True if a row was deleted, False if no such id existed.
501    """
502    correction = db.query(Correction).filter(Correction.id == correction_id).first()
503    if correction is None:
504        return False
505    db.delete(correction)
506    db.commit()
507    return True

224    """

226    useful fuzzy matches ("FLAG OF QUA-TOYNE PRINCIPALITY" ~ "QUA-TOYNE PRINCIPALITY": 67) from same-topic noise

245    Find this project's TM entries relevant to `source_text`.
246

260    """
261    if threshold is None:

263    if top_k is None:

265    lexical_min = get_setting("memory_lexical_min", 25) or 0
266    strong = get_setting("memory_strong_similarity", 0.90)
267
268    if corrections is None:
269        corrections = db.query(Correction).filter(Correction.project_id == project_id).all()
270    if not corrections:
271        return []

275

277    if not candidates:
278        return []
279
280    query = memory_text(source_text)
281    query_vector = embed_text(query)
282    stored_vectors = np.stack([decode_embedding(c.embedding) for c in candidates])
283
284    # Vectors are pre-normalized at encode time, so the dot product IS the cosine similarity.
285    similarities = stored_vectors @ query_vector
286
287    scored = []
288    for idx, sim in enumerate(similarities):
289        sim = float(sim)
290        if sim < threshold:
291            continue
292        c = candidates[idx]
293        if sim < strong and lexical_min and lexical_overlap(query, memory_text(c.source_text)) < lexical_min:
294            continue
295        rank = sim + (_CORRECTED_BONUS if entry_kind(c) == "corrected" else 0.0)
296        scored.append((rank, sim, c))
297    scored.sort(key=lambda t: t[0], reverse=True)
298

301    for _, sim, correction in scored:
302        if len(results) >= top_k:

304        final_key = correction.final_translation.strip().lower()
305        if final_key in seen_finals:
306            continue
307        seen_finals.add(final_key)
308        results.append((correction, sim))
309    return results

451                      ids: list[int] | None = None, apply: bool = False) -> list[dict]:
452    """

454    term is accepted, so old entries stop contradicting it).
455
456    mode "word":   whole words only, case-insensitive (WIWERN, not WIWERNY).
457    mode "prefix": words STARTING with `find` - the term and its Polish inflected forms: find "WIWERN" ->
458                   WIWERN, WIWERNY, WIWERNAMI, each keeping its own ending (WYWERN, WYWERNY, WYWERNAMI).
459    The replacement takes the letter case of what it replaces. Only `ids` are changed when given (the user unticked
460    the rest of the preview). apply=False is a dry run.

472            rest = m.group(1)
473            return _same_case(m.group(0)[:len(m.group(0)) - len(rest)], replace) + rest
474    else:
475        pattern = re.compile(rf"(?<!\w){word}(?!\w)", re.IGNORECASE)
476
477        def substitute(m):
478            return _same_case(m.group(0), replace)
479

481    changes = []

485            continue

487        if after == c.final_translation:
488            continue

490        if apply:

492    if apply and changes:

539        db.query(TranslationLog)
540        .filter(TranslationLog.variant == "zero_shot", TranslationLog.run_id.in_(run_ids))
541        .all()
542    )
543    zero_shot_by_pair = {(log.run_id, log.bubble_id): log.output_text for log in zero_shot_logs}
544
545    source_texts = {log.source_text for log in injected_logs}
546    corrections = (
547        db.query(Correction)
548        .filter(Correction.project_id == owner.project_id, Correction.source_text.in_(source_texts))
549        .order_by(Correction.created_at.desc())
550        .all()
551    )
552    final_by_source = {}
553    for c in corrections:
554        final_by_source.setdefault(c.source_text, c.final_translation)
555
556    return [
557        {
558            "source_text": log.source_text,
559            "similarity_score": log.similarity_score,
560            "page_id": log.page_id,
561            "created_at": log.created_at.isoformat() if log.created_at else None,
562            "zero_shot_output": zero_shot_by_pair.get((log.run_id, log.bubble_id)),
563            "memory_injected_output": log.output_text,
564            "final_correction": final_by_source.get(log.source_text),
565        }
566        for log in injected_logs
567    ]

Full usage trail for a correction: every bubble where it was injected as a hint, alongside the zero-shot counterfactual for that same bubble (when AB-logging caught one) and whatever the user eventually saved for that exact source text - so the memory browser can show not just "it fired" but "did it help, and did the user still have to fix it afterward" (see memory.js renderUsage).

Note: TranslationLog.matched_correction_id stores only the best (top-1) match per bubble; examples #2/#3 are in injection_json, but this trail lists top-1 hits only.
