services.translation_service

LLM Translation Service Module

This module acts as the localization (translation) engine for the application, bridging the gap between the extracted OCR text and a pluggable LLM translation backend (see services/providers/). It is responsible for context-aware, English-to-Polish translation of manga and comic speech bubbles.

Key Architectural Features: 1. Pluggable Backend: Delegates the actual API call to whichever provider is configured as active (see services/providers/__init__.py). 2. Batch Processing: Aggregates all text bubbles from a page into a single provider call (the other bubbles are each other's context). 3. Translation-Memory Injection (adaptive MT by in-context learning, Moslem 2024 ch. 4): before translating, each bubble's source is looked up in the project's TM (services/memory_service.py). Two lanes: - longer text ("fuzzy" lane): up to MEMORY_TOP_K similar entries injected as "examples" - EN -> PL PAIRS with similarity, kind (corrected / approved) and, for corrections, the rejected AI text; - short text ("exact" lane: interjections, sound effects): the user's latest translation of that EXACT line is injected as "exact". 4. Terminology: glossary terms found in the source are injected per bubble; afterwards every output is checked for each term (inflection-tolerant, services/terminology.py) and bubbles that missed one get ONE extra post-editing call that inserts the term and keeps the rest (glossary_postedit). 5. Case: an ALL-CAPS source gets an ALL-CAPS translation (translation_match_case) - deterministic, in code. 6. Zero-Shot vs. Memory-Injected Logging (the thesis experiment): for bubbles with a memory match, a counterfactual is translated with the IDENTICAL payload minus the memory fields - same glossary, same page context (the other bubbles ride along as context_only). Only memory differs, so a difference between the two outputs is the memory effect, not a glossary or context effect. memory_ab_sample_rate limits how many runs pay for that second call. Both sides are compared on the MODEL output (before post-editing / case normalization: TranslationLog.injection_json["model_output"]); output_text is what was shown. 7. Full provenance per bubble in TranslationLog.injection_json (see _injection_record) and memory_lane. 8. Optional DB Context: project_id/page_id/db are optional. Without them translation still runs, just without memory, glossary or logging (e.g. test_main.py's test_ocr_from_path()).

 51def is_caps_line(text: str) -> bool:
 52    """>= 90% of the letters are upper case (OCR sometimes reads one 'Is' in an all-caps line)."""
 53    letters = [c for c in (text or "") if c.isalpha()]
 54    if len(letters) < 2:
 55        return False
 56    upper = sum(1 for c in letters if c.isupper())
 57    return upper / len(letters) >= 0.9

 60def match_case(source: str, translation: str) -> str:
 61    """Upper-case the translation of an ALL-CAPS source line (Python's upper() handles ą->Ą, ż->Ż...)."""
 62    if translation and is_caps_line(source) and translation != translation.upper():
 63        return translation.upper()
 64    return translation

 67def _example(correction: Correction, score: float) -> dict:
 68    """One memory example as the model sees it: an EN -> PL pair (+ what the user rejected, for corrections)."""
 69    en = memory_text(correction.source_text) or correction.source_text
 70    pl = correction.final_translation
 71    kind = entry_kind(correction)
 72    if is_caps_line(en):
 73        pl = pl.upper()
 74    ex = {"en": en, "pl": pl, "similarity": round(float(score), 2), "kind": kind}
 75    rejected = (correction.ai_translation or "").strip()
 76    if kind == "corrected" and rejected and rejected.lower() != correction.final_translation.strip().lower():
 77        ex["rejected"] = rejected.upper() if is_caps_line(en) else rejected
 78    return ex

 81def _memory_payload_fields(bubble: dict, found: list[tuple] | None) -> dict:
 82    """
 83    Memory-related keys for one bubble's provider payload entry:
 84    "exact" (one verbatim translation) for the short-phrase lane, or
 85    "examples" (EN -> PL pairs, best first) for the fuzzy lane. Empty dict when the bubble has no memory match.
 86    """
 87    if not found:
 88        return {}
 89    if is_short_phrase(bubble["text"]):
 90        exact = found[0][0].final_translation
 91        return {"exact": exact.upper() if is_caps_line(bubble["text"]) else exact}
 92    return {"examples": [_example(c, s) for c, s in found]}
 93
 94
 95def _lane(bubble: dict, found) -> str | None:
 96    if not found:
 97        return None
 98    return "exact" if is_short_phrase(bubble["text"]) else "fuzzy"

101def translate_bubbles(
102    bubbles: list[dict],
103    project_id: int | None = None,
104    page_id: int | None = None,
105    db: Session | None = None,
106    context: list[dict] | None = None,
107) -> list[dict]:
108    """
109    Translate extracted speech bubble texts via the active LLM provider, with translation-memory examples,
110    glossary terms, terminology post-editing and A/B logging (see module docstring).
111
112    Params:
113        bubbles (list[dict]): A list of bubble dictionaries. Each dictionary must
114                              contain at least 'bubble_id' and 'text'.
115        project_id (int | None): Scopes memory / glossary lookups to this project. Skipped entirely if None.
116        page_id (int | None): Used to tag logged TranslationLog rows with their
117                          source page. Required (together with db) for logging.
118        db (Session | None): Active SQLAlchemy session, used for lookups and logging.
119        context (list[dict] | None): neighbouring bubbles sent as context_only (single-bubble retranslation).
120
121    Returns:
122        list[dict]: The original list of bubbles, mutated to include a new
123                    'translation' field containing the localized Polish text.
124    """
125    if not bubbles:
126        return bubbles
127
128    # Bubbles flagged skip (page numbers, "?!", "...": see utils/bubble_post.py) and empty ones are never sent to
129    # the LLM, never logged and never counted as memory hits.
130    for b in bubbles:
131        if b.get("skip") or not (b.get("text") or "").strip():
132            b["translation"] = ""
133    all_bubbles = bubbles
134    bubbles = [b for b in all_bubbles if not b.get("skip") and (b.get("text") or "").strip()]
135    if not bubbles:
136        return all_bubbles
137
138    MEMORY_TOP_K = get_setting("memory_top_k", 3)
139    MEMORY_SIMILARITY_THRESHOLD = get_setting("memory_similarity_threshold", 0.67)
140    MEMORY_AB_TEST_LOGGING = get_setting("memory_ab_test_logging", True)
141    AB_SAMPLE_RATE = float(get_setting("memory_ab_sample_rate", 1.0))
142    POSTEDIT = get_setting("glossary_postedit", True)
143    MATCH_CASE = get_setting("translation_match_case", True)
144    ACTIVE_MODEL_NAME = get_active_model_name()
145
146    provider = get_provider()
147    run_id = str(uuid.uuid4())
148
149    memory_enabled = project_id is not None and db is not None
150    logging_enabled = memory_enabled and page_id is not None
151
152    # 1. Memory + glossary lookups up front, before touching the LLM.
153    #    bubble_id -> [(Correction, cosine), ...] best first.
154    matches: dict[str, list[tuple]] = {}
155    glossary_by_bubble: dict[str, list[dict]] = {}
156    memory_failed = False
157    if memory_enabled:
158        glossary_terms = load_glossary(project_id, db)
159        tm_entries = db.query(Correction).filter(Correction.project_id == project_id).all()
160        for b in bubbles:
161            text = b["text"].strip()
162            try:
163                top = find_top_matches(text, project_id, db, top_k=MEMORY_TOP_K, corrections=tm_entries)
164            except Exception as e:
165                # embedder failed to load (offline first run, broken cache...): translate WITHOUT memory hints instead
166                # of failing the whole page. Reported once per page, health banner shows the cause.
167                if not memory_failed:
168                    print(f"[TRANSLATION] memory lookup failed, continuing without hints: {type(e).__name__}: {e}")
169                memory_failed = True
170                top = []
171            if top:
172                matches[b["bubble_id"]] = top
173            g = match_glossary(text, glossary_terms)
174            if g:
175                glossary_by_bubble[b["bubble_id"]] = g
176
177    memory_fields = {b["bubble_id"]: _memory_payload_fields(b, matches.get(b["bubble_id"])) for b in bubbles}
178
179    def glossary_field(bid: str) -> dict:
180        return {"glossary": glossary_by_bubble[bid]} if bid in glossary_by_bubble else {}
181
182    context_items = [
183        {"id": c["bubble_id"], "text": c["text"], "context_only": True}
184        for c in (context or []) if (c.get("text") or "").strip() and not c.get("skip")
185    ]
186
187    # 2. Main payload (memory + glossary where matched). This is the result that gets shown to the user.
188    texts_payload = context_items + [
189        {"id": b["bubble_id"], "text": b["text"], **memory_fields[b["bubble_id"]], **glossary_field(b["bubble_id"])}
190        for b in bubbles
191    ]
192    model_output = provider.translate(texts_payload)
193    shown_key_label = provider.current_key_label
194    shown_model = provider.current_model or ACTIVE_MODEL_NAME     # a key can have its own model (Settings)
195
196    # 3. Terminology check + constrained post-edit (one extra call, only for bubbles that missed a glossary term).
197    terms_info: dict[str, dict] = {}
198    final_text: dict[str, str] = {}
199    to_fix = []
200    for b in bubbles:
201        bid = b["bubble_id"]
202        draft = model_output.get(bid, "")
203        final_text[bid] = draft
204        if bid not in glossary_by_bubble:
205            continue
206        missing = missing_terms(glossary_by_bubble[bid], draft)
207        terms_info[bid] = {"checked": [g["target_term"] for g in glossary_by_bubble[bid]],
208                           "missing": [g["target_term"] for g in missing]}
209        if missing and POSTEDIT:
210            to_fix.append({"id": bid, "text": b["text"], "draft": draft, "missing_terms": missing})
211    if to_fix:
212        try:
213            edited = postedit_missing_terms(provider, to_fix)
214        except Exception as e:
215            edited = {}
216            print(f"[TRANSLATION] terminology post-edit failed, drafts kept: {type(e).__name__}: {e}")
217            for item in to_fix:
218                terms_info[item["id"]]["postedit_error"] = f"{type(e).__name__}: {e}"
219        for item in to_fix:
220            bid = item["id"]
221            new = (edited.get(bid) or "").strip()
222            info = terms_info[bid]
223            if not new:
224                continue
225            still = missing_terms(glossary_by_bubble[bid], new)
226            info["postedit"] = {"draft": item["draft"], "result": new,
227                                "still_missing": [g["target_term"] for g in still]}
228            # keep the edit only if it actually fixed something (never trade a fluent draft for a worse miss)
229            if len(still) < len(item["missing_terms"]):
230                final_text[bid] = new
231                info["postedit"]["applied"] = True
232            else:
233                info["postedit"]["applied"] = False
234
235    # 4. Counterfactual for the A/B experiment: identical payload, memory fields removed, same glossary and context.
236    zero_shot_raw: dict[str, str] = {}
237    zero_shot_key_label = None
238    zero_shot_model = None
239    ab_sampled = MEMORY_AB_TEST_LOGGING and logging_enabled and bool(matches) and random.random() < AB_SAMPLE_RATE
240    if ab_sampled:
241        counterfactual_payload = context_items + [
242            ({"id": b["bubble_id"], "text": b["text"], **glossary_field(b["bubble_id"])}
243             if b["bubble_id"] in matches else
244             {"id": b["bubble_id"], "text": b["text"], "context_only": True})
245            for b in bubbles
246        ]
247        try:
248            zero_shot_raw = provider.translate(counterfactual_payload)
249            zero_shot_key_label = provider.current_key_label
250            zero_shot_model = provider.current_model or ACTIVE_MODEL_NAME   # != shown_model = pair not comparable
251        except Exception as e:
252            # the shown translation is already paid for - a failed experiment call must not fail the page
253            print(f"[TRANSLATION] A/B counterfactual failed, skipped: {type(e).__name__}: {e}")
254            zero_shot_raw = {}
255
256    # 5. Apply the shown translation to every bubble and build the log rows (only if enabled).
257    log_rows = []
258    for b in bubbles:
259        bid = b["bubble_id"]
260        raw = model_output.get(bid, "")
261        translation = final_text.get(bid, "")
262        cased = match_case(b["text"], translation) if MATCH_CASE else translation
263        b["translation"] = cased
264
265        found = matches.get(bid)
266        if found and memory_enabled:
267            for correction, _ in found:
268                correction.reuse_count = (correction.reuse_count or 0) + 1
269                db.add(correction)
270
271        if not logging_enabled:
272            continue
273
274        lane = _lane(b, found)
275        injection = {
276            "lane": lane,
277            **memory_fields[bid],
278            "glossary": glossary_by_bubble.get(bid, []),
279            "batch_size": len(bubbles),
280            "context_bubbles": len(context_items),
281            "model_output": raw,
282            "case_normalized": cased != translation,
283        }
284        if bid in terms_info:
285            injection["terms"] = terms_info[bid]
286        if found:
287            injection["ab"] = "counterfactual" if bid in zero_shot_raw else ("not_sampled" if not ab_sampled else "failed")
288            # log only (never sent to the model): which memory entries these were, in the order of "examples" / the
289            # one "exact" entry - the editor's "Used from memory" panel links each one to the Memory page
290            injection["correction_ids"] = [c.id for c, _ in found]
291        glossary_json = json.dumps(glossary_by_bubble[bid], ensure_ascii=False) if bid in glossary_by_bubble else None
292        common = dict(page_id=page_id, bubble_id=bid, source_text=b["text"], model_used=shown_model,
293                      run_id=run_id, glossary_terms_used=glossary_json)
294
295        if found:
296            best_correction, best_score = found[0]
297            # The similarity threshold only applies to the fuzzy lane; exact-match hits have no threshold.
298            threshold_used = None if lane == "exact" else MEMORY_SIMILARITY_THRESHOLD
299            log_rows.append(TranslationLog(
300                **common, variant="memory_injected", output_text=cased,
301                matched_correction_id=best_correction.id, similarity_score=best_score, threshold_used=threshold_used,
302                key_label=shown_key_label, memory_lane=lane,
303                hints_json=json.dumps(memory_fields[bid], ensure_ascii=False),
304                injection_json=json.dumps(injection, ensure_ascii=False),
305            ))
306            if bid in zero_shot_raw:
307                zs_raw = zero_shot_raw[bid]
308                log_rows.append(TranslationLog(
309                    **dict(common, model_used=zero_shot_model or shown_model), variant="zero_shot",
310                    output_text=match_case(b["text"], zs_raw) if MATCH_CASE else zs_raw,
311                    matched_correction_id=best_correction.id, similarity_score=best_score,
312                    threshold_used=threshold_used, key_label=zero_shot_key_label, memory_lane=lane,
313                    injection_json=json.dumps({"lane": None, "counterfactual_of": lane,
314                                               "glossary": glossary_by_bubble.get(bid, []),
315                                               "batch_size": len(bubbles), "context_bubbles": len(context_items),
316                                               "model_output": zs_raw}, ensure_ascii=False),
317                ))
318        else:
319            log_rows.append(TranslationLog(
320                **common, variant="zero_shot", output_text=cased,
321                matched_correction_id=None, similarity_score=None,
322                key_label=shown_key_label, memory_lane=None,
323                injection_json=json.dumps(injection, ensure_ascii=False),
324            ))
325
326    if memory_enabled:
327        # Logging / reuse counters are secondary: a failed commit (old DB schema, "database is locked") must NOT
328        # throw away translations that were already paid for.
329        try:
330            if log_rows:
331                db.add_all(log_rows)
332            db.commit()
333        except Exception as e:
334            db.rollback()
335            print(f"[TRANSLATION] logging FAILED, translations kept: {type(e).__name__}: {e}")
336
337    return all_bubbles

201    to_fix = []
202    for b in bubbles:
203        bid = b["bubble_id"]
204        draft = model_output.get(bid, "")
205        final_text[bid] = draft
206        if bid not in glossary_by_bubble:
207            continue
208        missing = missing_terms(glossary_by_bubble[bid], draft)
209        terms_info[bid] = {"checked": [g["target_term"] for g in glossary_by_bubble[bid]],
210                           "missing": [g["target_term"] for g in missing]}
211        if missing and POSTEDIT:
212            to_fix.append({"id": bid, "text": b["text"], "draft": draft, "missing_terms": missing})
213    if to_fix:
214        try:
215            edited = postedit_missing_terms(provider, to_fix)
216        except Exception as e:
217            edited = {}
218            print(f"[TRANSLATION] terminology post-edit failed, drafts kept: {type(e).__name__}: {e}")
219            for item in to_fix:
220                terms_info[item["id"]]["postedit_error"] = f"{type(e).__name__}: {e}"
221        for item in to_fix:
222            bid = item["id"]
223            new = (edited.get(bid) or "").strip()
224            info = terms_info[bid]
225            if not new:
226                continue
227            still = missing_terms(glossary_by_bubble[bid], new)
228            info["postedit"] = {"draft": item["draft"], "result": new,
229                                "still_missing": [g["target_term"] for g in still]}
230            # keep the edit only if it actually fixed something (never trade a fluent draft for a worse miss)
231            if len(still) < len(item["missing_terms"]):
232                final_text[bid] = new
233                info["postedit"]["applied"] = True
234            else:
235                info["postedit"]["applied"] = False
236
237    # 4. Counterfactual for the A/B experiment: identical payload, memory fields removed, same glossary and context.
238    zero_shot_raw: dict[str, str] = {}
239    zero_shot_key_label = None
240    zero_shot_model = None
241    ab_sampled = MEMORY_AB_TEST_LOGGING and logging_enabled and bool(matches) and random.random() < AB_SAMPLE_RATE
242    if ab_sampled:
243        counterfactual_payload = context_items + [
244            ({"id": b["bubble_id"], "text": b["text"], **glossary_field(b["bubble_id"])}
245             if b["bubble_id"] in matches else
246             {"id": b["bubble_id"], "text": b["text"], "context_only": True})
247            for b in bubbles
248        ]
249        try:
250            zero_shot_raw = provider.translate(counterfactual_payload)
251            zero_shot_key_label = provider.current_key_label
252            zero_shot_model = provider.current_model or ACTIVE_MODEL_NAME   # != shown_model = pair not comparable
253        except Exception as e:
254            # the shown translation is already paid for - a failed experiment call must not fail the page
255            print(f"[TRANSLATION] A/B counterfactual failed, skipped: {type(e).__name__}: {e}")
256            zero_shot_raw = {}
257
258    # 5. Apply the shown translation to every bubble and build the log rows (only if enabled).
259    log_rows = []
260    for b in bubbles:
261        bid = b["bubble_id"]
262        raw = model_output.get(bid, "")
263        translation = final_text.get(bid, "")
264        cased = match_case(b["text"], translation) if MATCH_CASE else translation
265        b["translation"] = cased
266
267        found = matches.get(bid)
268        if found and memory_enabled:
269            for correction, _ in found:
270                correction.reuse_count = (correction.reuse_count or 0) + 1
271                db.add(correction)
272
273        if not logging_enabled:
274            continue
275
276        lane = _lane(b, found)
277        injection = {
278            "lane": lane,
279            **memory_fields[bid],
280            "glossary": glossary_by_bubble.get(bid, []),
281            "batch_size": len(bubbles),
282            "context_bubbles": len(context_items),
283            "model_output": raw,
284            "case_normalized": cased != translation,
285        }
286        if bid in terms_info:
287            injection["terms"] = terms_info[bid]
288        if found:
289            injection["ab"] = "counterfactual" if bid in zero_shot_raw else ("not_sampled" if not ab_sampled else "failed")
290            # log only (never sent to the model): which memory entries these were, in the order of "examples" / the
291            # one "exact" entry - the editor's "Used from memory" panel links each one to the Memory page
292            injection["correction_ids"] = [c.id for c, _ in found]
293        glossary_json = json.dumps(glossary_by_bubble[bid], ensure_ascii=False) if bid in glossary_by_bubble else None
294        common = dict(page_id=page_id, bubble_id=bid, source_text=b["text"], model_used=shown_model,
295                      run_id=run_id, glossary_terms_used=glossary_json)
296
297        if found:
298            best_correction, best_score = found[0]
299            # The similarity threshold only applies to the fuzzy lane; exact-match hits have no threshold.
300            threshold_used = None if lane == "exact" else MEMORY_SIMILARITY_THRESHOLD
301            log_rows.append(TranslationLog(
302                **common, variant="memory_injected", output_text=cased,
303                matched_correction_id=best_correction.id, similarity_score=best_score, threshold_used=threshold_used,
304                key_label=shown_key_label, memory_lane=lane,
305                hints_json=json.dumps(memory_fields[bid], ensure_ascii=False),
306                injection_json=json.dumps(injection, ensure_ascii=False),
307            ))
308            if bid in zero_shot_raw:
309                zs_raw = zero_shot_raw[bid]
310                log_rows.append(TranslationLog(
311                    **dict(common, model_used=zero_shot_model or shown_model), variant="zero_shot",
312                    output_text=match_case(b["text"], zs_raw) if MATCH_CASE else zs_raw,
313                    matched_correction_id=best_correction.id, similarity_score=best_score,
314                    threshold_used=threshold_used, key_label=zero_shot_key_label, memory_lane=lane,
315                    injection_json=json.dumps({"lane": None, "counterfactual_of": lane,
316                                               "glossary": glossary_by_bubble.get(bid, []),
317                                               "batch_size": len(bubbles), "context_bubbles": len(context_items),
318                                               "model_output": zs_raw}, ensure_ascii=False),
319                ))
320        else:
321            log_rows.append(TranslationLog(
322                **common, variant="zero_shot", output_text=cased,
323                matched_correction_id=None, similarity_score=None,
324                key_label=shown_key_label, memory_lane=None,
325                injection_json=json.dumps(injection, ensure_ascii=False),
326            ))
327
328    if memory_enabled:
329        # Logging / reuse counters are secondary: a failed commit (old DB schema, "database is locked") must NOT
330        # throw away translations that were already paid for.
331        try:
332            if log_rows:
333                db.add_all(log_rows)
334            db.commit()
335        except Exception as e:
336            db.rollback()
337            print(f"[TRANSLATION] logging FAILED, translations kept: {type(e).__name__}: {e}")
338
339    return all_bubbles

Translate extracted speech bubble texts via the active LLM provider, with translation-memory examples, glossary terms, terminology post-editing and A/B logging (see module docstring).

Params: bubbles (list[dict]): A list of bubble dictionaries. Each dictionary must contain at least 'bubble_id' and 'text'. project_id (int | None): Scopes memory / glossary lookups to this project. Skipped entirely if None. page_id (int | None): Used to tag logged TranslationLog rows with their source page. Required (together with db) for logging. db (Session | None): Active SQLAlchemy session, used for lookups and logging. context (list[dict] | None): neighbouring bubbles sent as context_only (single-bubble retranslation).

Returns: list[dict]: The original list of bubbles, mutated to include a new 'translation' field containing the localized Polish text.
