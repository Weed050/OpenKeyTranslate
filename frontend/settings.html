Quick start
  1. Get a free key: Groq or Google AI Studio (Gemini) - or use any OpenAI-compatible service, or a local Ollama / LM Studio.
  2. + Add key (or the empty row), pick the provider and paste the key.
  3. Press Test next to the key - the result appears right under it. Everything is saved when you leave a field, no restart.

OCR: ignored text

Bubbles whose text matches any of these regular expressions (one per line, case-insensitive, "contains" match) are dropped before translation - watermarks, site URLs, credits. Applies to pages processed from now on (no restart); use Re-OCR in the editor for pages already processed. Example: ^\W*\d+\W*$ also drops number-only bubbles.

Backup & move to another computer

One zip with everything: database (projects, corrections, glossary, logs), settings (without this PC's folder path), the .env file and all page images + OCR results. On the new computer install the app, open this page and import the zip - everything is put in the right place automatically.

Storage & uninstall

Everything OpenKeyTranslate keeps on this computer, with sizes. Caches and logs can be deleted here - they come back by themselves. Your work (projects, database, settings) is only shown here, never deleted from the app.

Uninstalling OpenKeyTranslate
  1. If you may come back: Export all data - one zip with projects, memory, glossary and settings.
  2. Delete the model caches above (they lie outside the app folders), unless another program uses PaddleOCR.
  3. Close the app: stop the backend (its console window, Ctrl+C).
  4. Delete these folders by hand:
    Press Check sizes.

A packaged version's uninstaller removes the program; the data folders stay unless you delete them - so a reinstall finds your projects again.
